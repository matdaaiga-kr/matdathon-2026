## 1. GitHub Copilot SDK 및 Microsoft Agent Framework의 효과적인 활용 (가중치: 25%)

두 필수 기술을 모두 올바르게 사용하고 있으며, 애플리케이션의 핵심 요소로 활용하고 있는가? Copilot SDK를 통한 모델 연결과 Microsoft Agent Framework를 활용한 에이전트 설계, 오케스트레이션, 도구 호출, 컨텍스트 처리 및 스트리밍을 함께 평가한다. 기능의 수보다 활용의 깊이를 중점적으로 본다.

## 2. 생산성 향상 효과 및 문제 적합성 (가중치: 18%)

명확한 대상 사용자가 겪는 실제적이고 구체적인 생산성 문제를 해결하며, 실질적이고 입증된 효과를 제공하는가?

## 3. Azure 클라우드 통합 (가중치: 18%)

Azure 인프라를 의미 있게 사용하고 실제로 배포했는가? 애플리케이션과의 관련성, 안전한 클라우드 네이티브 방식, 반복 가능한 배포, 안정성 및 관찰 가능성을 높이 평가하며, 필요 이상의 서비스를 형식적으로 추가한 경우에는 감점한다. Azure AI 또는 모델 서비스의 사용을 필수로 요구하거나 가산점 요소로 평가하지 않는다.

## 4. 기능 완성도 및 기술적 구현 (가중치: 16%)

애플리케이션이 처음부터 끝까지 정상적으로 작동하는가? 코드 품질, 아키텍처, 오류 처리, 성능 및 플랫폼에 적합한 구현 여부를 평가한다. 플랫폼 적합성에는 크로스 플랫폼 네이티브 애플리케이션 또는 반응형 웹 구현이 포함된다.

## 5. 사용자 경험 및 워크플로 설계 (가중치: 12%)

사용자 인터페이스가 직관적이고 사용 과정의 불편이 적은가? AI가 자연스럽게 통합되어 있는지, 지연과 오류를 적절히 처리하는지, 동작과 결과를 투명하게 전달하는지, 접근성을 고려하는지, 사용자가 통제권을 유지할 수 있는지를 평가한다.

## 6. 책임 있는 AI, 보안 및 신뢰 (가중치: 6%)

AI가 생성한 결과를 명확히 표시하고, 위험한 작업을 수행하기 전에 사용자의 확인을 받는가? 데이터 개인정보 보호, 환각 완화, 프롬프트 인젝션 대응 및 안전한 비밀 정보 관리를 평가한다.

## 7. 혁신성 및 독창성 (가중치: 5%)

기존 도구를 단순히 모방하지 않고, 생산성 향상을 위해 AI를 새롭고 창의적으로 활용했는가?
